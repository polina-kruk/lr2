# Лабораторная работа №6
# SIEM и события безопасности сервиса + учебные инциденты

## 1. Цель работы

Развернуть SIEM Wazuh, подключить к ней журналы межсетевого экрана, веб-сервиса (TLS), AAA (RADIUS) и домена Samba AD. Сгенерировать учебные инциденты и настроить правила корреляции для их выявления.

## 4. Корреляционные правила

**Таблица 2. Корреляционные правила** (`/var/ossec/etc/rules/local_rules.xml`)

| № | Правило | Условие | Источник | Статус |
|---|---|---|---|---|
| 1 | 106001 Port scan | 10 блокировок фаервола (87701) с одного IP за 2 мин | OPNsense | ✅ сработало |
| 2 | 106002 / 106012 SSH brute force | 5 ошибок входа SSH (5710 / 5760) с одного IP за 5 мин | Ubuntu auth.log | ✅ сработало |
| 3 | 106003 TLS error burst | 3 ошибки TLS на nginx (106013) с одного IP за 5 мин | nginx error.log | ✅ сработало |
| 4 | 106004 AAA reject burst | 3 RADIUS Access-Reject (106014) за 5 мин | radius.log | ✅ сработало |
| 5 | 106005 AD failures | 3 ошибки Kerberos (106015) за 5 мин | log.samba | ✅ сработало |

Фрагмент `local_rules.xml`:
```xml
<rule id="106001" level="10" frequency="10" timeframe="120">
  <if_matched_sid>87701</if_matched_sid>
  <same_source_ip />
  <description>LAB6: possible port scan - 10+ firewall blocks from $(srcip) in 2 min</description>
</rule>
<rule id="106002" level="10" frequency="5" timeframe="300">
  <if_matched_sid>5710</if_matched_sid>
  <same_source_ip />
  <description>LAB6: SSH brute force - 5+ logins with non-existent user from $(srcip) in 5 min</description>
</rule>
```

## 6. Выводы

Wazuh собрал в одном месте события межсетевого экрана, веб-сервиса, AAA и домена. Каждый инцидент лучше всего виден в своём источнике: сканирование — на фаерволе, подбор SSH — в auth.log, ошибки TLS — в журнале nginx, отказы AAA — в журнале FreeRADIUS, ошибки доменного входа — в журнале Samba AD. SIEM сводит их на одну шкалу времени и корреляциями превращает серии одиночных событий в понятные alerts: «сканирование», «подбор пароля», «серия ошибок TLS».

Для корректной работы SIEM важны синхронизированное время на всех узлах и достаточные ресурсы. Нехватка диска и памяти в лабораторной приводила к отказу компонентов Wazuh.

Доступ к SIEM ограничен минимально необходимыми потоками: агенты только на порты 1514/1515, пользовательская зона к SIEM не допускается. SIEM хранит журналы всей инфраструктуры и сама является ценной целью.
